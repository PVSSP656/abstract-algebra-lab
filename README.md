# Can Different Systems Be Mathematically the Same?

An undergraduate Abstract Algebra project for **TMAT302L at VIT Vellore**.

## Purpose

This project studies whether three six-element systems—numbers, permutations, and circular movement—can share the same underlying mathematical structure. The team will use group theory to examine operation tables, group properties, cyclic groups, generators, subgroups, homomorphisms, and isomorphisms.

## Current status

The project is in the **planning and mathematical-verification phase**. The three-system comparison is the default direction and will be checked and refined using the original project HTML and official course syllabus.

No mathematical results, implementation, deployment, or final technology stack are claimed yet.
