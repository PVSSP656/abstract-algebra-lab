# Can Different Systems Be Mathematically the Same?

An undergraduate Abstract Algebra project for **TMAT302L at VIT Vellore**.

## Purpose

This project investigates whether three visually different six-element systems can have the same underlying algebraic structure. It uses groups, cyclicity, generators, subgroups, Lagrange's theorem, homomorphisms, and isomorphisms.

## Current stage

**Stage 1 — mathematical foundation and verification**

The approved comparison is:

1. \(\mathbb Z_6\) under addition modulo 6.
2. The cyclic permutation group generated by \((1\ 2\ 3\ 4\ 5\ 6)\).
3. \(D_3\), the six symmetries of an equilateral triangle.

The first two systems are isomorphic; \(D_3\) is non-abelian and non-cyclic. The exact operations, table convention, operation tables, subgroup lists, orders, and proofs are fixed in the [mathematical specification](docs/MATHEMATICAL_SPECIFICATION.md).

No website UI has been built yet.

## Verify the mathematics

Run the independent Python checker:

```bash
python scripts/verify_math.py
```

It verifies the complete \(D_3\) table, group properties, element orders, distinct permutation powers, exact subgroup lists, the \(\mathbb Z_6\)-to-permutation isomorphism, and the \(D_3\) non-commutativity witness.
